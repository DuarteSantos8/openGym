# First-time lifter study

Run one English-language session with each of five first-time lifters. The owner facilitates. Use the same build, phone layout and task order for everyone. Record the build and device type on the [metrics sheet](metrics.md). Use a fresh disposable device profile for each participant, with English selected and the Beginner setting. Start at Home with no plan. Keep a separate prepared profile with a plan scheduled today for recovery between tasks.

Read the [consent script](consent.md) and wait for a yes before taking notes. Then say, “Please use the app as you normally would. You can think aloud, skip a task or stop. We are testing the app. You can enter pretend numbers. You do not need to exercise.”

Read only the wording in the middle column. Start timing after reading each prompt. Let the person try without hints. Stop on completion, when they choose to stop, or after three minutes. Record the outcome before helping them reach the next starting point. If a feature is unavailable in this build, record it as unavailable.

| Task | Read aloud | Facilitator’s completion check |
|---|---|---|
| 1. Get a plan | “You’re new to lifting. Get yourself a plan that fits your week.” | The participant answers the plan questions, confirms a recommendation and can see the saved routine in Plan. |
| 2. Start today | “Open the workout you would do today and get it ready to log.” | An active workout shows its first exercise. If task 1 left today as a rest day or produced no plan, switch to the prepared profile before starting the timer. |
| 3. Log a set | “Imagine you finished one set of the first exercise. Record it using pretend numbers.” | One set is marked complete in the workout. Then offer a break; leave the workout and return to Home for task 4. |
| 4. Look up a word | “You saw ‘RIR’ in a workout. Find out what it means and tell me in your own words.” | A glossary definition opens and the participant can describe how many more repetitions they think they could do. |
| 5. Start a warm-up | “Find a warm-up you can follow along with. Open it and show me the first movement.” | The session player opens on its first movement. End the disposable session and return to Home before task 6. |
| 6. Change a setting | “Change the default rest time between sets to a different value. Show me how you know it was saved.” | The participant reopens the workout setting and shows the new value. |

Finish by asking, “Which part would you change first, and why?” Use a single anonymous sentence in the sheet. The owner calculates outcomes after all five sessions. This short visit does not measure a completed first workout or a week of use.
