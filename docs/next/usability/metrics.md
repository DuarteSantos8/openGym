**Exit comment:**

**Facilitator resets between tasks, if any:**

Measure elapsed time to the observable completion or stop point. Describe a wrong turn or failed action concretely (for example, opened Plan twice looking for rest settings). Record zero when none occurred. Count help once the facilitator supplies a location, label or next step. A facilitator reset between tasks does not change the completed task’s score.

After five sessions, report each task’s unaided completions out of five, assisted completions, failures, skips and unavailable cases separately. Report the median time for unaided completions with its sample count; leave it blank if nobody completed unaided. Summarize repeated errors and the change each suggests. Give the owner the aggregate results for the grades in the beginner plan. Keep unmeasured criteria, including a week of use, pending.
