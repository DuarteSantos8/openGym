# Task EP-03: per-exercise volume trend in Stats

Read `docs/superpowers/briefs/WAVE-2-common.md` first. Epic outline:
`docs/superpowers/plans/EP-03-analytics.md`. Discovery this design is based on:
`docs/superpowers/evidence/EP-03-discovery/README.md` (verify every line reference in it against
the code; it is a proposal by another agent, not a fact).

## Approved scope

One increment: a **Volume** chart option in the Stats "Exercise progress" card, showing volume
per session for the selected exercise, with an honest inclusion note and a real data table.

Decisions already taken by the orchestrator:

- **No ECharts and no new dependency.** The existing `LineChart` draws one series fine. Task 3 of
  the epic outline (ECharts) is deferred to an owner decision and is not part of this task.
- **No module switch.** Basic stats are core, and this is one more option in an existing selector
  that is never selected by default. With the option not chosen, every existing Stats output must
  be identical.
- **Nothing is persisted.** The series is derived on read. No new field in `S`.
- Do not duplicate what `report.js` / `report-print.js` and the existing Stats cards already show
  (see "Already covered" in the discovery note).

## Deliverables

1. `frontend/src/lib/exercise-volume.js` and `exercise-volume.test.js`: a pure
   `exerciseVolumeSeries(S, exId, { days = 0, now = Date.now() })` that reuses the existing
   volume, unit and date helpers (`workoutVolume`, `exView`, `entriesForExercise`, `workoutAt`,
   `workoutDay`, the warm-up and bodyweight volume settings; confirm the real names). It returns
   the points plus counts of included and excluded sessions, with the exclusion reason.
   - Timed and cardio work, sessions with no completed reps, and old records that only have a
     whole-session `vol` are **excluded and counted**, never plotted as 0.
   - Assisted exercises: the logged load is the assistance, so the option is hidden for them.
   - The exercise's pinned unit decides the unit. Never mix kg and lb in one series.
   - Windows 7, 30, 90, 365 and All, cut at the local day boundary.
2. Tests first, covering at least: local-midnight boundary of the 7-day window, two sessions on
   one day, a workout with `d` only and no `start`, kg and lb pin, warm-ups counted on and off,
   bodyweight counted on and off, per-side, drop sets, dumbbells, timed and cardio, zero completed
   work, legacy record without entries, two entries of the same exercise in one workout.
3. `Stats.jsx`: the `Volume` option (only for reps exercises, not assisted, with at least one
   session of positive volume), the chart with the exercise's unit, a real `<table>` (Date, Sets,
   Volume) reachable without hover, an empty state, and one plain sentence stating how many
   sessions are included and how many are excluded and why.
4. Ranges: add `1W` to the shared `rangeOptions` so the 7-day window is usable, and extend the
   existing range tests for the cards that share it. If five segments overflow or become
   unreadable at 320 px in the real browser, keep the shared options as they are, give only the
   Exercise progress card the `1W` option, and say so in the handoff.
5. `Stats.ex-volume.test.jsx`: option visibility rules, chart points and unit, empty state,
   exclusion sentence, accessible table. Existing Stats tests stay green untouched.
6. Locale keys for every new string in every pack. Put them next to the existing Stats keys in
   each pack (another task adds a Nutrition block elsewhere in the same files).
7. Browser check with a synthetic profile at 320, 390 and 1280 px, dark and light, keyboard only:
   screenshots under `docs/superpowers/evidence/EP-03/`, console errors and failed requests
   listed. Bundle delta for the entry chunk and the Stats chunk against
   `docs/product/BASELINE_REPORT.md`.

## Acceptance

- Volume numbers for a fixture reconcile by hand with the logged sets (show the arithmetic for one
  session in the tasks file).
- No fake zeroes: an excluded session never appears as a point.
- Existing Stats output unchanged when Volume is not selected; all suites, build and checks green.
- The table and the sentence carry the same information as the chart.
