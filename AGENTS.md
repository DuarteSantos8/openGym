# Правила работы с openGym

## Локализация на этапе разработки

- Новые и изменённые UI-строки локализовать только для **en, ru, de**: английский — исходный текст без отдельного locale-файла, русский и немецкий — соответствующие пакеты в `frontend/src/locales/`.
- Это текущая оптимизация затрат времени, вычислений и объёма изменений на этапе разработки, **не сокращение языковой поддержки или функциональности продукта**.
- Остальные языки оставлять доступными: не удалять их из выбора языка, не удалять существующие переводы, пакеты, инструкции упражнений или механизмы локализации. Для новых непереведённых строк использовать штатный английский fallback.
- Не добавлять переводы или английские дубли в остальные пакеты только ради полноты набора ключей, если пользователь отдельно этого не попросил. Расширить локализацию можно позднее без изменения архитектуры.
- Сохранять проверки существующих переводов, непустых значений, форм множественного числа и `{n}`-подстановок. Проверки новых строк должны учитывать текущий объём en/ru/de и допустимый fallback остальных языков.
