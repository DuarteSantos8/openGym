# Exercise-name packs for de/es/fr (and it) plus a per-language "English name in parentheses" toggle

## What problem does this solve?

openGym ships a catalogue of 1,324 built-in exercises with English names. Users who run the
app in German, Spanish or French (the three most-requested languages after the existing pt-BR,
hu, it packs) still see every exercise labelled in English — acceptable for a logbook, but the
rest of the UI is fully translated, and translated exercise names make workouts, plans and
stats immediately readable without having to mentally map foreign labels.

Separately, the translated exercise names are always followed by the English name in
parentheses. That is helpful while learning the local term, but it is noise for an experienced
user who wants a clean, fully-localized list. Today there is no way to turn it off, and no way
to express the choice *per language* — and no way to fall back to pure English names when even
the translation is unhelpful.

## Proposed approach

- Add complete exercise-name packs for German, Spanish, French and Italian by translating the
  full 1,324-exercise catalogue. Each pack is authored as a JSON source file and generated by a
  one-off build script that fail-fast on unknown ids, empty values or an incomplete count, with
  a unit test asserting full catalogue coverage plus per-language translation rules.
- Existing languages without a pack (de-CH is a derived locale and inherits German) keep the
  current behaviour: English names, no toggle.
- Make the "(English name)" parenthetical a per-language user setting:
  - a persisted per-language map in the client store, defaulting to *shown* so existing
    profiles keep today's rendering;
  - Settings shows a single adaptive switch that reflects the active language (only when that
    language actually has a translated pack, so the option is hidden for languages that cannot
    use it) and remembers a separate choice for each language;
  - the app re-applies the exercise-name rendering when the setting changes.
- Add a companion **"English names only"** per-language toggle that skips the translation
  entirely and shows the original English name. It is independent of the parenthetical toggle,
  and while either is active the name is shown without the redundant counterpart.

No new dependencies. Training logic (rendering of logged sessions) is a pure helper behind the
existing i18n seam, covered by unit tests.
