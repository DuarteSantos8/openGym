Guida rapida

Questa guida copre installazione, primi allenamenti e avvio di un server personale. La guida completa e le sezioni avanzate sono in inglese.

Copertura italiana. Pagina iniziale, presentazione e guida rapida sono disponibili in italiano. Importazioni dettagliate, backup, configurazione completa, coach AI, server MCP, API e risoluzione dei problemi restano in inglese. Apri la documentazione completa in inglese.

Installazione su Android

Scarica l’APK firmato dal sito e aprilo sul telefono. Android potrebbe chiederti di autorizzare l’installazione da questa origine. openGym funziona senza account e conserva i dati sul dispositivo.

Scarica l’APK

Inizia un allenamento

Crea una routine o apri un allenamento vuoto, aggiungi esercizi e registra peso e ripetizioni per ogni serie. Il timer di recupero parte quando completi una serie. Puoi modificare l’allenamento salvato e controllare in seguito lo storico e i progressi.

Avvio con Docker

Per sincronizzare più dispositivi, avvia il server sul tuo hardware con Docker Compose. Il repository contiene il file Compose e le istruzioni aggiornate per la configurazione.

git clone https://github.com/DuarteSantos8/openGym.git
cd openGym
cp .env.example .env
docker compose pull
docker compose up -d

Prima di esporre il servizio su Internet, configura HTTPS e crea il primo account amministratore. Leggi la sezione self-hosting della guida inglese per variabili, backup, proxy inverso e aggiornamenti.
