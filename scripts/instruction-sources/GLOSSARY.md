# Brazilian Portuguese exercise glossary

Preferred terms keep the instruction pack consistent with Brazilian gym usage.

| English | Use in pt-BR | Avoid |
|---|---|---|
| abdomen / abs / engage your core | abdômen / contraia o abdômen | abdómen |
| calf / calves | panturrilha / panturrilhas | gémeos |
| hip | quadril | anca |
| shoulder blade | escápula | omoplata |
| rotator cuff | manguito rotador | coifa dos rotadores |
| dumbbell | halter | peso de mão |
| barbell | barra | barra de peso |
| Smith machine | máquina Smith | barra guiada, unless describing the bar |
| overhand grip | pegada pronada | pegada por cima |
| underhand grip | pegada supinada | pegada invertida / inversa |
| reverse grip | determine from the stated palm direction | pegada invertida / inversa |
| pull-up bar | barra fixa | barra de elevações |
| push-up | flexão de braços | flexão |
| set | série | conjunto |
| repetition / rep | repetição | repetiçãozinha |
| bodyweight | peso corporal | peso do corpo, when used as a category |
| starting position | posição inicial | posição de partida |
| resistance band / band | faixa elástica | banda |
| stability ball | bola de estabilidade | bola suíça |
| floor / ground | chão | piso |

Write instructions using Brazilian `você` conventions and neutral imperative
forms: `mantenha`, `contraia`, `eleve`, `retorne`. Avoid Portuguese (Portugal)
terms such as `ecrã`, `anca`, `abdómen`, `gémeos`, `ginásio` and second-person
forms such as `mantém`, `contrai`, `eleva`, `retorna`.
